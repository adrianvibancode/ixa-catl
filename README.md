# Ixa: Mar y Desierto

Videojuego de plataformas HTML5 listo para GitHub Pages.

## Archivos
- `index.html`: juego completo.
- `ixa-sprites.png`: tira horizontal transparente de 6 fotogramas.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` e `ixa-sprites.png` a la raíz del repositorio.
3. Abre **Settings > Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main`, la carpeta `/ (root)` y pulsa **Save**.
6. Espera uno o dos minutos y abre la dirección mostrada por GitHub Pages.

## Controles
- A/D o flechas: caminar.
- W, flecha arriba o Espacio: saltar.
- En pantalla táctil aparecen controles virtuales.
